## Cursor Cloud specific instructions

`residual-alpha` is a single-repo MVP: a Python quant engine computes valuations and writes static JSON, which a Next.js 16 (App Router, Turbopack, React 19) frontend renders. There is no database or backend API. CI builds `--source auto --recorded` from committed `tests/data` caches (no live fetch, no API keys). Optional Yahoo / J-Quants / EDINET fetch scripts are not run in CI and must not commit API keys.

- Dependencies are refreshed automatically on startup (`pip install -r requirements.txt` for `numpy`/`pytest`, `npm ci` for the frontend). No manual install is needed.
- `pytest` is installed to `~/.local/bin`, which is not on `PATH`. Run tests with `python3 -m pytest` (config in `pytest.ini`; sources under `scripts/` via `pythonpath`).
- Standard commands (see `README.md` / `package.json`): tests `python3 -m pytest`; lint `npm run lint`; build site data `python3 scripts/build_public_data.py --source auto --recorded`; fixture engine JSON `python3 scripts/build_public_data.py`; expand listings `python3 scripts/expand_universe.py --from topix-core30`; dev server `npm run dev` (serves `http://localhost:3000`, routes `/`, `/ranking`, `/stocks/<ticker>`).
- Optional `--source auto` reads cached prices (the complete series with more aligned returns among J-Quants daily AdjC and Yahoo chart; J-Quants wins ties; market is Yahoo Nikkei 225) and the first complete fundamentals source per name (EDINET XBRL → J-Quants FY → Yahoo timeseries). Recorded Yahoo charts cover TOPIX Core30. Recorded EDINET yuho XBRL covers the original 10 names plus Core30 extras with 3 beginning-book ROE years (including 9983 Aug FYE from November list days). EDINET doc type 140 (IFRS annual reports) is accepted beside 120. Partial yuho are not padded; auto uses Yahoo timeseries (2914 calendar-year transition). A partial or short higher-tier cache does not block a longer complete lower-tier cache. Ranking and stock JSON carry per-name `priceSource`, `fundamentalsSource`, `returnCount` (aligned daily returns used for beta), `roeCount` (ROE history years used for normalized ROE), `priceAsOf`, and `fundamentalsAsOf`. When `jquants_bars` is used, `meta.json` also carries `priceLagNote`: J-Quants free-plan bars can lag about 12 weeks; a paid Light plan is not required. Universe `meta.json` is the union across names. `scripts/expand_universe.py` adds TSE names from 4-digit tickers or recorded `topix_core30.json` (derives Yahoo / J-Quants / EDINET codes; not a live index crawl). `scripts/refresh_public_data.py`, `scripts/compact_yahoo_charts.py`, `scripts/compact_jquants_caches.py`, and `scripts/compact_edinet_xbrl.py` are operator commands, not CI and not a GitHub Actions cron. The committed site is `--source auto --recorded` from `tests/data`. Do not commit live `public/data` from operator `data/raw`; restore with `python3 scripts/build_public_data.py --source auto --recorded`.
- Before opening or updating a pull request, do one self-review of the branch diff. Look for architecture breaks (Python computes, Next.js displays JSON), missing financials coerced to 0, mixed fundamentals inside one name, live `public/data` from operator `data/raw`, API keys, and GitHub Actions cron. Fix what you find, then submit the PR.
- The frontend reads `public/data/rankings.json` and `public/data/stocks/*.json`. These are committed from `--source auto --recorded`. If you change the Python engine or recorded caches (`scripts/`, `tests/data/`), re-run `python3 scripts/build_public_data.py --source auto --recorded` before viewing the UI.
- Running `npm run dev` (or `next build`) regenerates `AGENTS.md` and `CLAUDE.md` via Next.js (`next.config.ts` `agentRules`). If they show as modified, commit them with your work to keep the tree clean; do not delete the `nextjs-agent-rules` block.
- Production deploy is Vercel (import the GitHub repo, or set `VERCEL_TOKEN` / `VERCEL_ORG_ID` / `VERCEL_PROJECT_ID` for the optional `deploy` workflow after `test` on `main`). Vercel builds only the Next.js app from committed `public/data`; no Python fetch on the platform. Not a cron.
